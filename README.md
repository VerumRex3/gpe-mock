# 戦闘モック（three.js）

チームの企画書（ゲーム名は伏せています）の戦闘部分を、Unity で作り始める前に手触りを確かめるためのモックです。
戦闘1戦（開始 → 勝敗 → もう一度）だけを遊べます。

**遊ぶ：** https://verumrex3.github.io/gpe-mock/
1台のキーボードを2人で使います。タイトル画面で 1P は SPACE、2P は ENTER を押すと始まります。

**カード一覧：** https://verumrex3.github.io/gpe-mock/cards.html （最新版のデータからゲームと同じ絵で描いています）

上の URL は常に最新版です。各バージョンは次の URL で遊べます（当時のまま固定）。

## 操作

| | 1P ルスカー（左） | 2P ラティシア（右） |
|---|---|---|
| カード選択 | A / D | ← / → |
| カードを使う・パリィを止める | SPACE | ENTER |
| 弾倉の弾丸を撃つ／アルカナを発動待ちにする | W | ↑ |
| 手札を引き直す | S | ↓ |
| 直前の行動を取り消す | Shift | BackSpace |

H キーか右上の歯車で、ルールと操作の説明を表示します。

## 画面（v0.4 から。戦闘案３の画面案に合わせた配置）

- 上の黒帯から敵のカード5枚を吊るし、下の黒帯に2人の手札（左がルスカー、右がラティシア）を並べます。背景は薄い空と山、地面の帯です。
- 左上に弾倉（上の段ほど次に撃つ弾）、左に照準の紋章、右に魔法陣（1〜5の順に埋まる）を置いています。
- 紋章の**赤丸の数字がコスト**、右下の小さな丸は弾倉の弾の数（ルスカー）／発動待ちのアルカナの数（ラティシア）です。
- 敵の頭上の黒いバーと赤い数字が行動値、その下が HP です。
- 左下・右下は引き直しと山札（山札・捨て札の枚数）です。中央の3つの菱形は画面案にあった飾りで、今のところ意味はありません。

## ルール（戦闘案３に準拠し、書かれていない部分は仮仕様）

- **勝利条件：** 翼竜の HP を0にするか、上に並ぶ敵の攻撃カード（赤）をすべて破壊すれば勝ち。2人とも倒れたら負け。
- **行動値：** ターンはありません。2人とも好きな順に操作でき、カードは使ったその場で発動します。カードを使うか手札を引き直すたびに敵の行動値が1減り、0になると敵がカードを1枚使い、行動値が元に戻ります（4。激昂後は3）。再型・占星統治は行動値を消費しません。
- **コスト：** 初期値3で上限なし。カードを使うと相方のコストが1回復します（行動値を消費しないカードを除く）。手札を引き直すと2人とも+1、敵が行動すると2人とも+1。引き直し自体にコストはかかりません。
- **弾丸（ルスカー）：** 再型で弾倉に1発ずつ装填します（最大5）。W で一番上の弾を撃ち、敵に5ダメージ（コスト1）。ラティシアの星霊の加護で、弾倉の次弾に崩壊・抵抗・特攻を付けられます。撃った弾は加護を残したまま捨て札に行き、山札を経て手札に来ます（手札からも撃てます）。速射は、次に弾丸を撃ったときに次弾も続けて撃ちます。
- **アルカナ（ラティシア）：** 占星統治で魔法陣に1つずつ補填します（最大5）。↑ で番号順に「発動待ち」にします（コスト1）。発動待ちのアルカナは、次に敵が使うカードに5ダメージ。ルスカーの運命超過で付けた属性がカードの種類（攻撃・防御・特殊）と合うと+5。カードの HP が0になると破壊され、そのカードの行動も止まります。敵が行動したあと、魔法陣のアルカナは発動待ちかどうかに関わらずすべて捨て札に行きます。
- **星霊の加護：** 崩壊＝命中後、次の敵の行動が終わるまで、敵・味方が行動するたびに敵に3ダメージ。抵抗＝命中で敵の次の攻撃ダメージを半減（重ねるとその次も）。特攻＝弾丸の攻撃力+3。
- **取り消し：** 1P は Shift、2P は BackSpace。敵が次に行動するまでの間、自分の直前の行動を取り消せます（相方がそのあとに行動していたら不可）。引くカードは毎回山札全体からランダムに選ぶので、取り消してから引き直しても同じカードが来るとは限りません。
- **パリィ（v0.2 から継続）：** パリィカードを使うと「構え」になり、次の敵の攻撃カードでタイミングバーが出ます。中央で止めるほど防御値が大きく、ピンクの範囲なら成功効果も発動。「全員でパリィ」のカード（守護の盾・共鳴の盾）を構えていると2人ともバーに参加します。
- **連携（v0.2 から継続）：** 金枠のカードです。敵が次に行動するまでに2人とも金枠を使うと連携効果が上乗せされます。金枠にパリィが含まれるときは、次の敵の攻撃で2人ともパリィに成功すると発動します。
- **敵：** 上の5枚は表向きで、それぞれ HP を持ちます。敵は壊れていないカードからランダムに1枚使います。HP が半分を切ると激昂し、行動値が3になります。
- **防御値：** HP より先に削られる盾です。使い切らなかった分は溜まっていきます。

## 戦闘案３からの補足・変更点

| 項目 | 戦闘案３ | このモック |
|---|---|---|
| 弾丸・アルカナの使い方 | 「使用すると」とだけ記載 | 自分で選んで使う（S／↓）。コストは使うときに払う |
| アルカナのコスト | 記載なし | 弾丸に合わせて1 |
| コスト上限 | 記載なし | 上限なし |
| 引き直しのコスト | 記載なし | なし（両者+1・行動値−1） |
| 崩壊の続く期間 | 記載なし | 次の敵の行動が終わるまで |
| 運命超過の上昇量 | 記載なし | +5 |
| パリィ・連携 | 記載なし | v0.2 のものを残し、それぞれ数枚をデッキに追加 |
| 敵カード | 記載なし | 攻撃3枚・防御1枚・特殊1枚を表向きに並べる |
| 激昂 | 記載なし | v0.2 の「1ターン2回行動」を「行動値4→3」に読み替え |

## 数値の目安

自動対戦ボットで「上手い2人の勝率9割台後半・初心者想定で4分の3程度」になるよう、敵 HP 80・敵カード HP 12〜15 にしています。撃破までは敵の行動16回前後（味方の行動は60回ほどで、v0.2 の10ターン前後と同じくらいの長さ）。勝ちのうち2〜4割は攻撃カードの全破壊によるものです。

## 素材について

- 画像素材は使っていません。キャラクター・敵・背景・カード・アイコンはすべて Canvas 2D でコードから描いています。
- フォント：[M PLUS Rounded 1c](https://fonts.google.com/specimen/M+PLUS+Rounded+1c)（Google Fonts／SIL Open Font License）
- 描画：[three.js](https://threejs.org/) r170（MIT License、CDN から読み込み）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `src/data.js` | カード・敵・数値の定義。**バランス調整はここだけで完結します** |
| `src/game.js` | 戦闘ルール本体（描画から独立） |
| `src/view.js` | three.js による描画と演出 |
| `src/main.js` | 入力と進行（敵の行動の流れ） |
| `cards.html`, `src/cards.js` | カード一覧ページ（`data.js` から描画） |
| `tools/serve.py` | ローカル確認用サーバー |
| `v0.1/`〜`v0.5/` | 各バージョンの固定コピー（同名の git タグから書き出したもの。編集しない） |

## ローカルで動かす

```bash
python tools/serve.py
```

`http://localhost:8000/` を開きます。ES モジュールを使っているので、`index.html` をファイルとして直接開いても動きません。
