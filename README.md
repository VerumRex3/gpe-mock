# 戦闘モック（three.js）

チームの企画書（ゲーム名は伏せています）の戦闘部分を、Unity で作り始める前に手触りを確かめるためのモックです。
戦闘1戦（開始 → 勝敗 → もう一度）だけを遊べます。

**遊ぶ：** https://verumrex3.github.io/gpe-mock/
タイトル画面で A / D（または ← / →）を押すと「一人で遊ぶ」「二人で遊ぶ」を切り替えられます。一人は SPACE で開始。二人は1台のキーボードを2人で使い、1P が SPACE、2P が ENTER を押すと始まります。
一人モードで直接始めたいときは https://verumrex3.github.io/gpe-mock/?solo を開きます。一人モードの山札の分け方は、タイトルで W / S を押して切り替えます（`?solo&deck=mixed` で「混ぜる」から始まる）。

**カード一覧：** https://verumrex3.github.io/gpe-mock/cards.html （最新版のデータからゲームと同じ絵で描いています）

上の URL は常に最新版です。各バージョンは次の URL で遊べます（当時のまま固定）。

## 操作

**二人モード**

| | 1P ルスカー（左） | 2P ラティシア（右） |
|---|---|---|
| カード選択 | A / D | ← / → |
| カードを使う・パリィを止める | SPACE | ENTER |
| 弾倉の弾丸を撃つ／アルカナを発動待ちにする | W | ↑ |
| 手札を引き直す（1ターン1回） | S | ↓ |
| 直前の行動を取り消す | 左Shift | BackSpace |
| ターン終了 | E | 右Shift |
| アイテムを使う | 1 / 2 / 3（どちらが押してもよい） | 同左 |

**一人モード**

| 操作 | キー |
|---|---|
| カード選択 | A / D（← / → でも可） |
| カードを使う・パリィを止める | SPACE（ENTER でも可） |
| ルスカーの弾丸を撃つ | W（↑ でも可） |
| ラティシアのアルカナを発動待ちにする | E |
| 手札を引き直す | S（↓ でも可） |
| 直前の行動を取り消す | Shift（BackSpace でも可） |
| アイテムを使う | 1 / 2 / 3 |

H キーか右上の歯車で、ルールと操作の説明を表示します。

## 画面（v0.4 から。戦闘案３の画面案に合わせた配置）

- 上の黒帯から敵のカード5枚を吊るし、下の黒帯に2人の手札（左がルスカー、右がラティシア）を並べます。背景は薄い空と山、地面の帯です。
- 左上に弾倉（上の段ほど次に撃つ弾）、左に照準の紋章、右に魔法陣（1〜5の順に埋まる）を置いています。
- 紋章の**赤丸の数字がコスト**、右下の小さな丸は弾倉の弾の数（ルスカー）／発動待ちのアルカナの数（ラティシア）です。
- 敵の頭上の黒いバーと赤い数字が行動値、その下が HP です。
- 左下・右下は引き直しと山札（山札・捨て札の枚数）です。v0.6 まで中央にあった3つの菱形（画面案の飾り）は、v0.7 でアイテム欄に置き換えました。
- 一人モードでは、下の黒帯に手札を並べ、右にアイテム欄、左下に引き直しと山札（2人分の合計）を1組だけ置きます。手札は、山札キャラ別なら左3枚がルスカー・右3枚がラティシア、混ぜるなら中央に5枚です。カードの縁の色と名札が持ち主（紫＝ルスカー、橙＝ラティシア）です。

## 一人モードと二人モード（v0.7〜）

会議で「一人プレイにしたい（テストプレイでマルチの意味が薄かった）」という案が出たため、判断用に両方を遊べるようにしました。v0.11 からは進行も違います。二人モードでは、片方のプレイヤーが行動値を一方的に使ってしまう問題があったので、ターン制に戻しました。一人モードは行動値制のままです。

| | 二人モード | 一人モード |
|---|---|---|
| 進行 | ターン制（v0.11〜）。2人とも好きなだけ動き、2人とも「ターン終了」を押すと敵が行動 | 行動値制。カードを使う・引き直すたびに敵の行動値 −1、0 で敵が行動 |
| コスト | ターン開始時に3に戻る（持ち越しなし） | 初期3・上限なし。行動ごとに相方+1、引き直し・敵の行動で両方+1 |
| 敵 | HP 140、攻撃カードのダメージ+2。1ターンに1回行動（激昂後は2回） | HP 90。行動値4（激昂後は3） |
| 主人公 | ルスカーとラティシア | 同じ（2人とも場に出て、HP・コスト・弾倉／魔法陣を別々に持つ） |
| 操作する人 | 2人（1人1キャラ） | 1人で2キャラ |
| 手札 | それぞれ自分のデッキから3枚 | 標準は山札キャラ別で、ルスカー3枚＋ラティシア3枚（使った枠は持ち主の山札から引くので常に 3:3）。切り替えで「2人のデッキを1つに混ぜて5枚」も選べる |
| カードのコスト | 自分の紋章から払う | カードの持ち主の紋章から払う |
| 相方のコスト+1 | なし（ターン制） | ルスカーのカードを使うとラティシアが+1（逆も同じ）。交互に使うと得 |
| 弾丸・アルカナ | 1P が W、2P が ↑ | W と E に分けて1人で両方 |
| パリィ | 構えた人がそれぞれバーを止める（全員でパリィは2本） | バーは1本。止めた位置を構えている全員に使う |
| 取り消し | 自分の直前の行動だけ。ターン終了も、相方が押す前なら取り消せる | 直前の行動から順に |
| 倒れたとき | 倒れた人は操作できない | 倒れたキャラのカードは手札に残るが使えない（キャラ別なら3枠がまるごと使えなくなる。混ぜるなら引き直しで流せる） |

### 一人モードの山札：キャラ別（3:3）と混ぜる（5枚）

v0.9 で、標準を「キャラ別・手札 3:3」に変えました。バランス調整のしやすさを比べた結果です。

- **キャラ別（3:3）：** 撃った弾丸はルスカーの山札に、使ったアルカナはラティシアの山札に戻ります。カードの巡り方が二人モードと同じになるので、一人と二人の差は「1人で全部決める」「パリィのバーが1本」くらいになります。数値を変えたときも、一人と二人がそろって動きます。
- **混ぜる（5枚）：** 弾丸やアルカナが34枚以上の山札に薄まるので、HP を削る力が落ち、カード全破壊寄りになります。手札が片方のキャラに偏ることもあります。一人モードだけ別の調整が要ります。

ボットで、攻撃カードの HP を変えたときの「勝ちのうち全破壊」の割合（上手い人／初心者想定、各3000戦）：

| 攻撃カードの HP | 二人 | 一人・キャラ別 | 一人・混ぜる |
|---|---|---|---|
| 13・13・15（v0.7。v0.10 もこの HP だが、敵の HP と攻撃が違う） | 9%／53% | 10%／44% | 91%／89% |
| 16・16・18（v0.8〜v0.9） | 3%／27% | 4%／19% | 59%／63% |
| 19・19・21 | 2%／17% | 3%／12% | 44%／53% |

キャラ別は、どの数値でも二人モードとほぼ同じ所に来ます。混ぜるは一人モードだけが大きくずれます。

## ルール（戦闘案３に準拠し、書かれていない部分は仮仕様）

- **勝利条件：** 翼竜の HP を0にするか、上に並ぶ敵の攻撃カード（赤）をすべて破壊すれば勝ち。2人とも倒れたら負け。
- **ターン制（二人モード、v0.11〜）：** 2人とも好きな順に、好きなだけカードを使えます（制限時間なし。カードは使ったその場で発動）。済んだら「ターン終了」（1P は E、2P は右Shift）。2人とも押すと敵が1回行動し（激昂後は2回）、次のターンになります。コストはターン開始時に3に戻り、使い残しは持ち越しません。手札の引き直しは1ターンに1回で、コストは増えません。v0.2 のターン制と違い、カードはターン終了でまとめて発動せず、使ったその場で発動します。コスト上限の増減（1P 3→10／2P 10→3）も戻していません。
- **行動値（一人モード）：** ターンはありません。2人とも好きな順に操作でき、カードは使ったその場で発動します。カードを使うか手札を引き直すたびに敵の行動値が1減り、0になると敵がカードを1枚使い、行動値が元に戻ります（4。激昂後は3）。再型・占星統治は行動値を消費しません。
- **コスト：** 初期値3で上限なし。カードを使うと相方のコストが1回復します（行動値を消費しないカードを除く）。手札を引き直すと2人とも+1、敵が行動すると2人とも+1。引き直し自体にコストはかかりません。
- **弾丸（ルスカー）：** 再型で弾倉に1発ずつ装填します（最大5）。W で一番上の弾を撃ち、敵に5ダメージ（コスト1）。ラティシアの星霊の加護で、弾倉の次弾に崩壊・抵抗・特攻を付けられます。撃った弾は加護を残したまま捨て札に行き、山札を経て手札に来ます（手札からも撃てます）。速射は、次に弾丸を撃ったときに次弾も続けて撃ちます。
- **アルカナ（ラティシア）：** 占星統治1枚で魔法陣に2つ補填します（最大5。v0.6 までは1つ。「攻撃カード全破壊での勝利が無理筋」という意見を受けて、アルカナが溜まる速さを2倍にした）。↑ で番号順に「発動待ち」にします（コスト1）。発動待ちのアルカナは、敵が使うカードに5ダメージ。ルスカーの運命超過で付けた属性がカードの種類（攻撃・防御・特殊）と合うと+5。カードの HP が0になると破壊され、そのカードの行動も止まります。敵が1回行動するごとに、発動待ちのアルカナが番号の若い順（1→2→3…）に1つだけ当たって捨て札に行きます。残りは魔法陣に残り、番号が1つずつ繰り上がります（v0.5 までは、発動待ちが全部まとめて当たり、そのあと魔法陣が空になっていました）。
- **星霊の加護：** 崩壊＝命中後、次の敵の行動が終わるまで、敵・味方が行動するたびに敵に3ダメージ。抵抗＝命中で敵の次の攻撃ダメージを半減（重ねるとその次も）。特攻＝弾丸の攻撃力+3。
- **取り消し：** v0.6 までは敵の行動をまたいで取り消せてしまう不具合があったので、v0.7 で直しました。1P は左Shift（一人モードは Shift）、2P は BackSpace。敵が次に行動するまでの間、自分の直前の行動を取り消せます（相方がそのあとに行動していたら不可）。引くカードは毎回山札全体からランダムに選ぶので、取り消してから引き直しても同じカードが来るとは限りません。
- **バフアイテム（仮、v0.7）：** 1 / 2 / 3 キーで使います。1戦に各1回、行動値を消費しません。闘志の香＝ルスカーの次の攻撃+6、守りの護符＝2人とも防御+6、魔力の結晶＝2人ともコスト+2。二人モードではどちらが押しても使え、取り消しはできません。中身と数値は会議メモの「バフアイテムを用意」を受けた仮のものです。
- **パリィ（v0.2 から継続）：** パリィカードを使うと「構え」になり、次の敵の攻撃カードでタイミングバーが出ます。中央で止めるほど防御値が大きく、ピンクの範囲なら成功効果も発動。「全員でパリィ」のカード（守護の盾・共鳴の盾）を構えていると2人ともバーに参加します。
- **敵：** 上の5枚は表向きで、それぞれ HP を持ちます。敵は壊れていないカードからランダムに1枚使います。HP が半分を切ると激昂し、行動値が3になります。
- **防御値：** HP より先に削られる盾です。使い切らなかった分は溜まっていきます。

## 数値の目安

二人モード（ターン制）と一人モード（行動値制・山札キャラ別）は進行が違うので、敵の HP と攻撃を別々に調整しています（`data.js` の `RULES.turn` がターン制用）。目安は「上手い人で勝率9割台半ば・全破壊3割前後、初心者想定で8割前後」です。

| | 二人モード（ターン制） | 一人モード（行動値制） |
|---|---|---|
| 敵 HP | 140 | 90 |
| 攻撃カードの HP（爪撃・尾薙ぎ・噛みつき） | 13・13・15 | 13・13・15 |
| 攻撃カードのダメージ（同上） | 22・15・26（共通の値＋2） | 20・13・24 |
| 1回の敵の行動までの手数 | 1ターン（コスト3ずつ。激昂後は1ターンに2回行動） | 行動値4（激昂後は3） |

ボットは2種類です。「上手い人」は毎回いちばん良さそうな行動を選び、パリィは中央付近で止め、アイテムも使います。「初心者想定」は3回に1回くらい適当なカードを使い、パリィの精度はばらつき、アイテムは使いません。ターン制では、2人とも打つ手が無くなったらターン終了します。各4000戦の結果です。

| | 勝率 | 勝ちのうち全破壊 | 撃破までの長さ |
|---|---|---|---|
| 二人・上手い人 | 96% | 29% | 8.3ターン（敵の行動 11.7回） |
| 二人・初心者想定 | 81% | 51% | 9.8ターン（敵の行動 13.3回） |
| 一人・上手い人 | 96% | 29% | 敵の行動 14.7回 |
| 一人・初心者想定 | 88% | 69% | 敵の行動 14.9回 |

- ターン制にすると、敵が1回動くまでに味方が使えるコストが2人で6になり、行動値制（2人で4手）より手数が増えます。最初にコスト4で試したところ、4ターンほどで勝ってしまったので、コストを3に下げ、敵を硬く・強くしました。
- 撃破までは8〜10ターンで、v0.2 のターン制（10ターン前後）と同じくらいの長さです。
- アルカナは敵が1回行動するごとに1つ当たる仕組みのままです。ターン制では敵の行動回数が減るので、全破壊のために敵の HP を多めにして戦闘を長くしています。
- 全破壊での勝ちを増やしたい・減らしたいときは、`data.js` の攻撃カードの `hp` を動かすのが一番効きます。勝率も一緒に動くので、二人モードは `RULES.turn` の `enemyHp`・`dmgBonus`、一人モードは `enemyMaxHp` と攻撃カードの `dmg` で戻してください。調整には `node tools/bot.mjs` が使えます（`'{"duoProgress":"av"}'` を渡すと、二人モードを行動値制で測れます）。

## ローカルで動かす

```bash
python tools/serve.py
```

`http://localhost:8000/` を開きます。ES モジュールを使っているので、`index.html` をファイルとして直接開いても動きません。
