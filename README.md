# 戦闘モック（three.js）

チームの企画書（ゲーム名は伏せています）の戦闘部分を、Unity で作り始める前に手触りを確かめるためのモックです。
戦闘1戦（開始 → 勝敗 → もう一度）だけを遊べます。

**遊ぶ：** https://verumrex3.github.io/gpe-mock/
1台のキーボードを2人で使います。タイトル画面で 1P は SPACE、2P は ENTER を押すと始まります。

## 操作

| | 1P（左下・アタッカー） | 2P（右下・バッファー） |
|---|---|---|
| カード選択 | A / D | ← / → |
| カードを場に出す・パリィを止める | SPACE | ENTER |
| 手札を引き直す（マナ1） | W | ↑ |
| ターン終了（2人そろうとカードが発動） | S | ↓ |

H キーか右上の歯車で、ルールと操作の説明を表示します。

## ルール（このモックでの仮仕様）

- **ターン制：** 味方のターンは2人が同時に操作します（制限時間なし）。出したカードは画面中央の「場」に並ぶだけで、まだ発動しません。2人とも「ターン終了」を押すと、2P → 1P の順に、それぞれ出した順でまとめて発動し、そのあと敵のターンに移ります。2P のバフ・デバフは、同じターンの 1P の攻撃に必ず乗ります。
- **マナ：** ターン開始時に上限まで全回復し、カードを場に出した時点で減ります。上限は 1P が 3→10（毎ターン+1）、2P が 10→3（毎ターン−1）です。2P の「魔力供給」で 1P の次のターンのマナを増やせるので、序盤は 2P が支え、終盤は 1P が決める流れになります。
- **パリィ：** パリィカードが発動すると「構え」になり、次の敵の通常攻撃でタイミングバーが出ます。中央で止めるとカードの防御値が最大で、離れるほど減り、バーの端では 0 です。ピンクの範囲で止めれば成功効果も発動します。パリィは 1P・2P どちらのデッキにも入っています。
  - 「全員でパリィ」のカード（守護の盾・共鳴の盾）を構えていると、パリィカードを出していない人もバーに参加します。それぞれ自分の止めた位置で決まる防御値を得ます。
- **連携：** 金枠のカードです。同じターンに2人とも金枠を1枚以上出すと連携が成立し、発動時に連携効果が上乗せされます（組み合わせは自由）。成立しているかどうかは場の間に表示されます。
  - 金枠にパリィが含まれるときは、すぐには発動しません。次の敵の通常攻撃で2人ともパリィに成功すると発動します（連携パリィ）。このときは、パリィカードを出していない人もバーに参加します。
- **敵：** 画面上部に伏せた5枚から、毎ターン1枚を使います。何が来るかは分かりません。特殊行動はパリィできません。HP が半分を切ると激昂し、1ターンに2回行動します。
- **防御値：** HP より先に削られる盾です。パリィ自体にダメージを無効にする効果はなく、得た防御値がそのまま攻撃を受け止めます。使い切らなかった分は上限なく溜まり、次に攻撃を受けたときに先に使われます。

## 企画書からの変更点

| 項目 | 企画書 | このモック |
|---|---|---|
| 進行 | リアルタイム | ターン制。カードはターン終了でまとめて発動。リアルタイムなのはパリィのバーだけ |
| 連携 | 同時タイミングで使用 | 同じターンに2人とも金枠を出す |
| コスト | 時間で増えるゲージ（2人共通） | ターン開始時に全回復。上限は 1P が増え、2P が減る |
| 役割 | 記載なし | 1P アタッカー／2P バッファー。パリィは両方が持つ |
| 敵の手札 | 図のみ（上部5枚） | 伏せた5枚から毎ターン1枚。通常攻撃はパリィ可、特殊行動は不可 |

## 素材について

- 画像素材は使っていません。キャラクター・敵・背景・カード・アイコンはすべて Canvas 2D でコードから描いています。
- フォント：[M PLUS Rounded 1c](https://fonts.google.com/specimen/M+PLUS+Rounded+1c)（Google Fonts／SIL Open Font License）
- 描画：[three.js](https://threejs.org/) r170（MIT License、CDN から読み込み）

## ファイル構成

| ファイル | 内容 |
|---|---|
| `src/data.js` | カード・敵・数値の定義。**バランス調整はここだけで完結します** |
| `src/game.js` | 戦闘ルール本体（描画から独立） |
| `src/view.js` | three.js による描画と演出 |
| `src/main.js` | 入力とターン進行 |
| `tools/serve.py` | ローカル確認用サーバー |

## ローカルで動かす

```bash
python tools/serve.py
```

`http://localhost:8000/` を開きます。ES モジュールを使っているので、`index.html` をファイルとして直接開いても動きません。
